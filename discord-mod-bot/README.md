# 🛡️ Discord Guardian Bot — بوت حماية السيرفر

بوت ديسكورد ذكي يحمي السيرفر من السب والشتم والتنمر والعنصرية والتحرش، مع محرك مضاد للتلاعب بالكلمات.

## ⚙️ آلية الحماية (لماذا هو "ذكي")

عندما يحاول شخص التحايل على الفلتر (مثل كتابة `ك.ل.ب`، `كلببببب`، `k1ll y0urself`، أو استبدال الحروف بأرقام عربية زي `3، 7، 5`)، الفلتر يمر بعدة طبقات قبل ما يقرر:

1. **تطبيع الحروف العربية**: توحيد أشكال الألف (أ إ آ ← ا)، والتاء المربوطة، والياء، وإزالة التشكيل بالكامل.
2. **فك تشفير الأرابيزي والليتسبيك**: تحويل `3 ← ع`, `7 ← ح`, `5 ← خ`, إلخ إلى الحرف العربي الأصلي.
3. **ضغط الحروف المكررة**: `كلببببب` تتحول إلى `كلب` تلقائياً.
4. **كشف التباعد المتعمد**: إزالة كل النقاط/المسافات/الشرطات بين الحروف لكشف كلمات مثل `س ب ك` أو `f.u.c.k`.
5. **التطابق التقريبي (Fuzzy Matching)** عبر خوارزمية Levenshtein: يكشف الأخطاء الإملائية المتعمدة في الكلمات الخطيرة (عنصرية/تحرش) حتى لو تغيّر حرف أو حرفين.
6. **نظام درجات خطورة** (low → critical) يحدد العقوبة المناسبة تلقائياً.
7. **نظام إنذارات تصاعدي**: 3 إنذارات = تايم آوت، 5 = تايم آوت أطول، 7 = طرد، 10 = حظر (قابل للتعديل بالكامل من `config.json`).

## 🚀 التشغيل

```bash
npm install
cp .env.example .env
# افتح ملف .env وحط فيه التوكن و CLIENT_ID و GUILD_ID
npm run deploy   # تسجيل أوامر السلاش (مرة وحدة، أو كل ما تضيف أمر جديد)
npm start        # تشغيل البوت
```

## 🔑 من وين أجيب القيم المطلوبة في .env

- **DISCORD_TOKEN**: من https://discord.com/developers/applications ← اختر تطبيقك ← Bot ← Reset Token.
- **CLIENT_ID**: من نفس الصفحة ← General Information ← Application ID.
- **GUILD_ID**: فعّل Developer Mode في ديسكورد (User Settings ← Advanced) ← اضغط يمين على السيرفر ← Copy Server ID.

### الصلاحيات المطلوبة عند دعوة البوت (OAuth2 URL Generator)
Scopes: `bot`, `applications.commands`
Permissions: `Manage Messages`, `Moderate Members`, `Kick Members`, `Ban Members`, `Send Messages`, `Read Message History`, `View Channels`

⚠️ تأكد إن رتبة البوت في السيرفر **أعلى** من رتب الأعضاء العاديين حتى يقدر يسوي Timeout/Kick/Ban، وفعّل خاصية **Message Content Intent** من صفحة Developer Portal (Bot ← Privileged Gateway Intents).

## 🛠️ التخصيص

- **إضافة/حذف كلمات**: استخدم أوامر `/addword` و `/removeword` مباشرة من ديسكورد، أو عدّل `data/badwords.json` يدوياً.
- **تغيير العقوبات**: عدّل `config.json` (مدة التايم آوت، عتبات الإنذارات، الرتب المستثناة، إلخ).
- **روم اللوقز**: أنشئ روم باسم `mod-logs` (أو غيّر الاسم في `config.json` → `logChannelName`) والبوت راح يسجّل فيه كل مخالفة تلقائياً بشكل embed مفصّل.
- **اختبار الفلتر**: استخدم أمر `/testfilter` وحط أي نص تشك فيه، وراح يوريك هل بينكشف ولاش وليش.

## 📁 هيكل الملفات

```
├── index.js                # نقطة تشغيل البوت الرئيسية

├── config.json              # إعدادات العقوبات والاستثناءات
├── data/
│   ├── badwords.json        # قاعدة الكلمات الممنوعة (قابلة للتوسيع)

├── utils/
│   ├── normalizeText.js     # محرك تطبيع النصوص (مضاد التلاعب)
│   ├── filter.js            # محرك الفحص والمطابقة
│   └── db.js                # تخزين/قراءة الإنذارات
├── .env.example
└── package.json
```

## 📌 ملاحظة مهمة

قائمة `data/badwords.json` المرفقة تحتوي أمثلة أساسية بعدة تصنيفات (سب، إهانات، تنمر، عنصرية، تحرش). يفضّل توسّعها بكلمات ولهجات إضافية حسب طبيعة أعضاء سيرفرك عبر `/addword` — كل ما زادت القائمة، زادت دقة الحماية.
